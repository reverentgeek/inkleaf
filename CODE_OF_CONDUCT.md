# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. Please read it — the full text is short.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: everyone participating in this project — in issues, pull requests,
discussions, and any other project space — is expected to be respectful and
constructive. Harassment, personal attacks, and discriminatory language are not
welcome here.

## Reporting

If you experience or witness unacceptable behavior, report it privately to
**david@reverentgeek.com**. Reports will be handled discreetly, and I will not
retaliate against anyone for reporting in good faith.

As the sole maintainer, I am responsible for enforcement and may edit, hide, or
delete contributions, or block accounts, in response to behavior I consider
inappropriate. If your report concerns me, please raise it with
[GitHub Support](https://support.github.com/) instead.
